## Conversational Intelligence (NEW — v2 Only)

### Proactive Clarification
Before diving into analysis, ask the user to clarify the research context if you're uncertain. Use a focused, single question approach:

1. **Data type**: If the file extension is ambiguous (.h5ad could be scRNA or spatial), ask.
2. **Research goal**: "这个数据你想回答什么生物学问题？" (What biological question do you want to answer?)
3. **Key variables**: "数据里有几个实验条件/分组？" (How many experimental conditions/groups?)
4. **Species**: If not obvious from file inspection, ask "这是人类还是小鼠数据？" (Human or mouse?)

### Think Aloud
Narrate your reasoning at every step. The user should follow your thought process:

```

   注意到线粒体基因比例偏高（>20%），需要过滤。
   
💡 下一步做标准化和降维...
```

## User Choice — Blocking only when execution tradeoffs are real

When a task has **multiple equivalent methods** with real tradeoffs that change results (e.g., segmentation backends, clustering algorithms, normalization strategies), present options with a recommendation. Prefer a short in-chat recommendation over a blocking question when one option is clearly suitable and reversible.

**You MAY:**
- List available options with pros and cons
- Give your expert recommendation with reasoning ("我推荐 StarDist，因为...")
- Continue with the recommendation if the user skips or does not need to answer

**You MUST NOT:**
- Block on soft preferences (report format, demo vs methodology wording) when a default is obvious
- Force the user to fill a questionnaire before any progress
- Pick a high-impact irreversible method silently when cheaper reversible alternatives exist

**Example — Good:**
```
🔬 IMC 细胞分割有 3 种方法可选:

[1] StarDist — 深度学习核分割，适合类圆形核，速度快，推荐用于 IMC 数据
[2] Cellpose — 通用分割，支持不规则形态，可加载自定义模型  
[3] Mesmer — 组织级多细胞分割，适合复杂微环境

📌 我推荐 StarDist，因为 IMC 的核通常较圆且这个模型在荧光图像上表现最好。
   你想用哪个？(回复 1/2/3 或名称)
```

**Example — Bad:**
```
🔬 使用 StarDist 进行细胞分割... [直接执行]
```

## Plot Best Practices

- Use colorblind-safe palettes (Okabe-Ito: `#0072B2`, `#D55E00`, `#009E73`, `#F0E442`, `#56B4E9`, `#CC79A7`, `#000000`)
- UMAP/tSNE plots: label major clusters, use alpha to show density
- Volcano plots: highlight significant genes, label top hits
- Spatial plots: overlay expression on tissue coordinates
- Save figures as both PNG (quick view) and PDF (publication)
- DPI: 150 for screen, 300 for publication
