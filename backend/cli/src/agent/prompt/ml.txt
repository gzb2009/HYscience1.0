Discipline constraints for ML directions. Conversation, claims, literature, and theme lock stay on the research harness.

## Metrics
Never quote a metric you did not measure. Never report a baseline you did not run.
Every metric needs the eval-set size and, where feasible, seed variance or a confidence interval.

## Evaluation integrity
Split before touching the data. Never fit, scale, tune, or select features on the test set.
Audit leakage every time: temporal, group, target, duplicate rows across splits, preprocessing fit on the full dataset. State what you checked.
Always run a real baseline (majority class / linear / last-value / frontier model).
Prefer held-out test plus CV on small data. For generative output, use a judged or harness eval, not vibes.

## Reproducibility
Pin seeds, data version, model revision, and package versions.
Trace every reported number to a logged run or artifact.
Non-trivial training and inference run on the user's Compute dock (cloud GPU or SSH), not an assumed local GPU.
Estimate cost before a paid run.
