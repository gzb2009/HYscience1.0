Five minutes from zero to a running research session. No account required.

<Steps>
  <Step title="Install">
    ```bash
    npm install -g @hysci/hyscience
    ```

    Or without a global install, `npx hysci` runs the same workbench in one step. The install script (`curl -fsSL https://hyscience.sh/install | bash`) drops a standalone `hyscience` binary into `~/.hyscience/bin`, and platform binaries are attached to every [GitHub release](https://github.com/HYscience/hyscience/releases).
  </Step>
  <Step title="Set a provider key">
    ```bash
    export ANTHROPIC_API_KEY=sk-ant-...   # or OPENAI_API_KEY, GEMINI_API_KEY, ...
    ```

    Any provider works — bring your own key and it stays on your machine. `hyscience keys add` gives you an interactive sign-in for providers that support it. See [Models](/hyscience/models) for routing and reasoning-effort tiers.
  </Step>
  <Step title="Open the workspace">
    ```bash
    hyscience
    ```

    The command starts a local server and opens the browser workspace: file tree, editor, terminal, and session history, with inline rendering for molecules, structures, genomes, and plots. See [Workspace](/hyscience/workspace).
  </Step>
  <Step title="Give it a goal">
    Ask for the outcome, not the steps. The default `research` agent plans, reads, codes, runs, and reports:

    ```text
    Reproduce the headline result of arXiv:2305.13245 on a small model
    and tell me whether it holds at 125M parameters.
    ```

    Prefer the terminal? One-shot runs work without the browser:

    ```bash
    hyscience run "Profile train.py and find the input-pipeline bottleneck"
    ```
  </Step>
  <Step title="Optional: connect HYcloud">
    ```bash
    hyscience login
    hyscience status
    hyscience wallet
    ```
  </Step>
</Steps>

## Verify the install

```bash
hyscience --version
hyscience models        # configured providers and models
hyscience skill list    # installed skills
```
