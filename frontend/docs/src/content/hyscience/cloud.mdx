HYscience never requires an account: bring-your-own-key usage is free and never gated. HYscience Cloud is the managed platform, and connecting to it is optional. HYscience Cloud only meters the models it serves.

## What connecting adds

- **A managed model route.** Curated frontier models billed from a prepaid wallet, so you do not need per-provider keys. The default endpoint is `app.hyscience.ai` (override with `HYSCIENCE_API_BASE`).
- **Spend controls.** Managed/BYOK toggles for LLM and compute spend, per surface, in **Settings → Billing** on the dashboard.
- **Synced service credentials.** Store cloud and ML keys (Hugging Face, W&B, Modal, and others) once on your account and pull them to any machine.
- **Research graphs.** Record sessions and findings into HYscience Graphs, the durable research map.

## Link your account

<Steps>
  <Step title="Log in">
    ```bash
    hyscience login
    ```
    Opens your browser to approve the device. On headless or CI machines, pass `--no-browser` and paste a key, or run `hyscience login --key thk_...` with a key created at `app.hyscience.ai/cli`.
  </Step>
  <Step title="Verify">
    ```bash
    hyscience status
    ```
    One answer to "what's my HYscience Cloud state?" — the connected user and device, synced-credential count, wallet balance and lifetime spend, recent usage, whether managed compute is available, and the bundled `hysci-graph` companion version.
  </Step>
  <Step title="Sync credentials">
    ```bash
    hyscience sync
    ```
    Refreshes synced service credentials after you change them on the dashboard.
  </Step>
</Steps>

## Model routing and billing

Key routing is per-provider and automatic: if you set a BYOK key for a provider, HYscience uses it; otherwise the request goes through the HYscience Cloud managed route and debits your wallet.

```bash
hyscience wallet         # wallet balance and current key routing
hyscience wallet topup   # opens the Plan tab — $50 or $200, one-time or recurring monthly
```

Flip managed versus BYOK per surface (LLM and compute) in **Settings → Billing**. BYOK works on every plan.

## Where credentials live

Connected, your account holds the canonical copy of every synced credential; the local `~/.config/hyscience/credentials.json` is a mirror you can delete and re-pull with `hyscience sync`. In BYOK mode, keys exist only on your machine — see [Security](/hyscience/security) for the storage and subprocess rules.

## Account commands

| Command | Use |
| --- | --- |
| `hyscience login` | Authenticate via browser; `--key thk_...` or `--no-browser` for headless machines. |
| `hyscience status` | Connection, user, device, and synced credential count. |
| `hyscience sync` | Re-pull synced service credentials from the dashboard. |
| `hyscience devices` | List authenticated devices; revoke from the Devices tab on the dashboard. |
| `hyscience logout` | Disconnect this machine. BYOK keeps working. |
