## Link your account

<Steps>
  <Step title="Log in">
    ```bash
    hyscience login
    ```
    Opens your browser to approve the device. On headless or CI machines, pass `--no-browser` and paste a key, or run `hyscience login --key thk_...` with a key created at `app.hyscience.ai/cli`.
  </Step>
  <Step title="Verify">
    ```bash
    hyscience status
    ```
  </Step>
  <Step title="Sync credentials">
    ```bash
    hyscience sync
    ```
  </Step>
</Steps>

## Wallet

```bash
hyscience wallet         # wallet balance and current key routing
hyscience wallet topup   # opens the Plan tab — $50 or $200, one-time or recurring monthly
```

## Account commands

| Command | Use |
| --- | --- |
| `hyscience login` | Authenticate via browser; `--key thk_...` or `--no-browser` for headless machines. |
| `hyscience status` | Connection, user, device, and synced credential count. |
| `hyscience sync` | Re-pull synced service credentials from the dashboard. |
| `hyscience devices` | List authenticated devices; revoke from the Devices tab on the dashboard. |
| `hyscience logout` | Disconnect this machine. BYOK keeps working. |
